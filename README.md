# Kids alarm clock

A DIY red/orange/green wake-up clock for two kids: firmware (Seeed XIAO ESP32-C3 + 12 WS2812B LEDs), a phone page to set it up, 3D-printed case, and a browser simulator that runs the real clock code against the 3D model.

- **Simulator:** published to GitHub Pages from `main` (see the repo's Pages link).
- **How the repo is laid out and how to build:** [AGENTS.md](AGENTS.md).
- **Models and the simulator scene:** [cad/README.md](cad/README.md).
